# Case Study: PartioBot

**Showcase:** [partio-bot](https://github.com/alexanderomobile/partio-bot)
**Статус:** ✅ MVP завершён
**Исходники:** приватный репозиторий

## Задача

Telegram-бот для совместных расходов: события, коды приглашения, равное деление, минимизация переводов.

## Стек

Python · aiogram 3 · FastAPI · SQLAlchemy · MySQL · Docker · pytest

## Функциональные блоки

Events · Expenses · Balance Engine · Group Linking · Domain Layer (messenger-agnostic)

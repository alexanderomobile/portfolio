# Case Study: Optimum Real Estate Bot

**Showcase:** [optimum-real-estate-bot](https://github.com/alexanderomobile/optimum-real-estate-bot)
**Статус:** 🔄 Production pilot
**Исходники:** приватный репозиторий

## Задача

Мультиязычный бот для агентов недвижимости (Хургада): запрос на любом языке → поиск в MySQL/RAG → ссылки на карточки сайта (13 языков).

## Стек

python-telegram-bot · MySQL · ChromaDB · OpenAI · WordPress Houzez · Polylang · REST plugin

## Функциональные блоки

Query Translate · Property Search · Response + WP links · Ingest · WP Sync · Contact Guard

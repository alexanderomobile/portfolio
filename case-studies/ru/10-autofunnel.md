# Case Study: AutoFunnel

**Live:** https://autofunnel.optimum-ltd.com/
**Status:** ✅ Production · первый боевой пользователь, реальные клиенты

---

## Задача

Малому бизнесу нужны автоворонки продаж в мессенджерах, но каждая площадка устроена по-своему:
свои вебхуки, свои кнопки, свои окна отправки, свои ограничения на медиа. Собрать воронку —
значит либо платить за семь разных сервисов, либо писать интеграции руками.

AutoFunnel — один визуальный редактор, один движок и одна лента переписки на семь каналов.

## Функционал

Визуальный редактор воронок (девять типов узлов: сообщение, условие, действие, сбор данных,
оплата, запись на услугу, A/B-тест, формула, заметка), триггеры по ключевым словам,
комментариям, сторис, метке источника, расписанию и оплате, CRM с сегментами, рассылки
и серии писем, лид-магниты, база знаний, продажа билетов с проверкой QR на входе, приём
оплаты через восемь платёжных подключений и возвраты, единая лента переписки с ответом
оператора, кабинет на тринадцати языках.

## Польза для бизнеса

Заменяет семь отдельных интеграций одним кабинетом: воронка собирается мышью и работает
одинаково в Telegram, Instagram и остальных каналах. Деньги идут напрямую на счёт владельца —
платформа не берёт процент с оборота и не держит средства.

## Стек

Python 3.11 · FastAPI · MariaDB · vanilla JS (без сборщика) · systemd · LXC · Cloudflare Tunnel ·
Telegram Bot API · Meta Graph API (Instagram, Messenger, WhatsApp) · VK Callback API · MAX API ·
MTProto (Telethon) для сторис

## Функциональные блоки

Каналы · Редактор воронок · Движок · CRM · Рассылки · Билеты · Платежи · Аналитика · Лента

## Инженерные решения

**Лестница старшинства триггеров.** Событие достаётся триггеру, который сказал о нём больше:
метка источника → ключевые слова → общий. Без этого один «перехват всего» съедал бы все
остальные сценарии — что и случилось однажды на боевых данных.

**Медиа отправляется номерком, а не файлом.** После первой отправки площадка возвращает свой
идентификатор загруженного файла, и дальше уходит он. Замер на боевом ролике 50 МБ:
94 с → 0,5 с, наружу ноль байт.

**Решения принимаются свойством, а не текстом.** Meta переводит тексты ошибок на язык
получателя, поэтому разбор по словам работает на английском и молча ломается на арабском.
Все такие развилки читают числовые коды.

**Храповик размера модулей.** У каждого модуля свой потолок; когда он исчерпан, домен
выносится в отдельный модуль, а порог не поднимается. Дважды за историю проекта потолок
опускали после выноса, чтобы освободившееся место нельзя было тихо съесть обратно.

**Мутационное тестирование как условие приёмки.** Двадцать одна тысяча тестов сама по себе
ничего не доказывает: тест, проверенный только зелёным прогоном, — это описание, а не сторож.
422 скрипта ломают по одному правилу каждый и обязаны получить красный.

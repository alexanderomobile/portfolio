# Case Study: RAG Documentation Assistant

**Showcase:** [rag-documentation-assistant](https://github.com/alexanderomobile/rag-documentation-assistant/blob/main/README.md)
**Status:** ✅ Production

---

## Задача

Консольный RAG-ассистент по технической документации.

## Функционал

Ответы по базе знаний, semantic search, кэш повторов, метрики RAGAS.

## Польза для бизнеса

Сокращает время поиска в документации, снижает нагрузку на поддержку, уменьшает риск ошибок из «памяти» сотрудников.
